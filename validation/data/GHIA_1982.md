# Ghia cavity reference data

`ghia_1982.csv` contains the tabulated centreline velocities from:

> Ghia, U., Ghia, K. N., and Shin, C. T. (1982). *High-Re solutions for
> incompressible flow using the Navier–Stokes equations and a multigrid method*.
> Journal of Computational Physics **48**, 387–411. Tables I and II.

The numerical transcription was cross-checked against two public source files:

* [ivan-pi/ghiav.txt](https://gist.github.com/ivan-pi/caa6c6737d36a9140fbcf2ea59c78b3c),
  which includes the complete Re=100/400/1000 `v` table;
* [Khadim-Hussain10/lid-driven-cavity-cfd](https://github.com/Khadim-Hussain10/lid-driven-cavity-cfd),
  whose notebook reproduces the `u` table and the benchmark comparison.

The `v(Re=400, x=0.9063)` entry is `-0.23827` in the gist; that source itself notes that
this particular printed value is disputed. It is retained as a cited transcription, not
silently replaced. Coordinates are in a unit square, velocity is normalised by lid speed,
and the centreline orientation is `u(x=0.5,y)` / `v(x,y=0.5)`.

For the primary Re=400 error metric, `validation/lid_cavity.py` excludes only the isolated
`x=0.9063` `v` point, while retaining `v_max_error_all`/`v_rms_error_all` over every printed
point. This is a data-quality exception, not a solver tolerance adjustment; the anomaly is
also discussed in the [CFD Online thread](https://www.cfd-online.com/Forums/main/88848-lid-driven-cavity-flow-re400.html).
